🤖 Evidence-driven security assessment — miniCISO staff

A native replication of miniCISO (agentic security staff). Nine specialist roles run a disciplined, evidence-driven workflow: collect tiered evidence, form hypotheses, and only promote a candidate to a Finding once it has linked evidence, a GO gate and a pass through Security QA. Recon surfaces candidates — never findings. Delivery is blocked until every finding clears QA. It is an assessment discipline, not a guarantee — human judgment and authorization stay with the operator.
