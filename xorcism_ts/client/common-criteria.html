🏆 Common Criteria — Security Targets

ISO/IEC 15408 (CC:2022) — define the TOE and its Security Target, claim the Security Functional Requirements from Part 2, and pick an EAL: the assurance worklist is seeded automatically from the EAL package (CC Part 5 defines exactly which components each level comprises). Under EUCC (Reg. (EU) 2024/482) the AVA_VAN level — not the EAL — sets the assurance level (AVA_VAN.1–2 → substantial, AVA_VAN.3–5 → high), which drives the CRA Art. 27 presumption of conformity.
